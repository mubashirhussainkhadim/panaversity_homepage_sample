# Panaversity homepage sample

An **unofficial replica / concept redesign** of the [panaversity.org](https://panaversity.org/) homepage, made for visual and design review only.

This project is **not affiliated with, endorsed by or operated by Panaversity**. Panaversity, PIAIC, GIAIC and Operation Badar names and logos belong to their respective owners. Courses, enrolment, exams and learner accounts exist only on the official website: <https://panaversity.org/>.

## What is in here

- `index.html`: the whole page in one file (HTML, CSS and a little vanilla JS). Open it in a browser. It follows the light/dark preference and has an on-load notice saying it is a replica.
- `svgs/`: the three redesigned animated SVGs used on the page
  - `career-orbit.svg`: the career-path orbit
  - `fte-hub.svg`: the Digital FTE hub
  - `circuit-bg.svg`: the circuit-line background
- `logos/`: the logos embedded in the page, wrapped as SVG (the artwork is the original raster images, not redrawn vectors)

Colours and fonts follow the current panaversity.org brand (Poppins and Rubik, `#1cd98e` green, `#050316` ink, `#031811` deep green).
